# תור עבודה מאוחד — DROPHAVOC
עודכן: 30.10.2026. זהו מקור המעקב העדכני; דוחות ישנים אינם אישור לתקינות הגרסה החדשה.

הגרסה המקומית נמצאת ב-work/source. המשחק הציבורי, האתר וה-APK עדיין לא עודכנו. פרסום בסיום הבדיקות כבר אושר על ידי בעל המשחק; אין אישור להוצאות.

## סדר ביצוע
1. **שליטה ויציבות — בבדיקה.** תוקנו בקוד התנגשויות קירות ורמפות, מעברים קדמיים ואחוריים ומדרגות בכל 16 הבתים. 21 בדיקות עברו, כולל שני לקוחות בחדר 1V1. נותר לבדוק תנועה ומשחק ידניים, ניתוק והשהיה. Esc פותח חזרה למשחק/יציאה ללובי. נעילת העכבר משתמשת ב-Pointer Lock; מסגרת Claude עלולה לחסום אותה ולכן יש קישור לפתיחה עצמאית. אין לטעון שניתן לעקוף חסימת iframe.
2. **גרפיקה ומצלמה — מימוש מקומי, אימות חלקי.** נוספו מרקמי קרקע/אספלט/עץ/קירות, הפרדת משטחי כביש בצמתים וצמצום ריצוד עומק. רכבים עם גוף מעוגל, חלונות, תאורה וארבעה צבעים. מצלמת נהיגה רחבה מאחור עם בדיקת קירות. שמות מרוחקים מותאמים לגודל קריא. נותר לבדוק נהיגה, ריצוד בתנועה, הסתרה נכונה של שמות, ביצועים וטלפון.
3. **אחיזת נשקים — פתוח.** נשקים ארוכים הונמכו והוזזו מהכוונת. נותר לכוון ולאמת אחיזת אקדח וסכין וכל נשק בכל דמות, כוונה, טעינה וזריקה. סכין נזרקת ללא הגבלת מלאי; נזק, קיר וקצב זריקה עברו בדיקה.
4. **תיבות ואיסוף — מימוש מקומי.** עץ רגיל וכחול נדיר, מכסה מונפש וחלל פנימי; נשק, אפוד, קסדה ומטבע/XP נפלטים ונשארים עד איסוף ידני. השרת מאמת טווח, קו ראייה ולקיחה אחת. בדיקות עברו: אין פרס אוטומטי בפתיחה ואין איסוף כפול. נותר אימות חזותי בשני לקוחות ובנייד, איזון והצבת שלל בלי חדירה לקירות.
5. **חיים ומגן — בוצע בקוד ובבדיקות.** תקרה 200 HP ו-200 מגן, כולל HUD וריפוי. מתחילים עם 200 HP; המגן נאסף. נדרש לוודא מול כוונת המשתמש האם גם המגן צריך להתחיל מלא, לפני שינוי איזון נוסף.
6. **עולם ומשחקיות — חלקי.** רחובות, 16 בתים עם חדרים וקומה עליונה, דלתות וחלונות פתוחים, עצים, תאורה, ציוד וצניחה. כניסה/יציאה מרכב ונהיגה מסונכרנות אצל המארח. נותר ליטוש נתיבי בוטים, צניחה משותפת, גגות, מחסות וקצב קרב. לכתוב GAME_DESIGN ו-UI_FLOW עם כללים מקוריים, ניצחון, התקדמות וממשק פשוט; מפת בתים לבדה אינה השלמת החזון.
7. **רשת וחברים — חלקי.** אימון מקומי, יצירה/רשימה/רענון/הצטרפות לחדרים ציבוריים ופרטיים, קישור והזמנת כמה חברים. בדיקת שרת לשני לקוחות 1V1 עברה. נותר 2V2 עם ארבעה לקוחות, הזמנות דרך הממשק, יציאה/חזרה, ניתוק ומניעת מעבר לבוטים במקרה כשל. לבדוק תאימות גרסת לקוח/שרת לפני פרסום.
8. **אדמין בבחירת הבעלים — מימוש חלקי.** Owner מנהל תפקידים מאומתים, הרשאות נשמרות ונבדקה מניעת הסלמה. נותר להגדיר את זהות הבעלים האמיתית בדרך פרטית ולבדוק UI, שחקנים, חסימה, הענקת ציוד ומטבע, Audit והגבלות. לא הוגדר אדם כאדמין ללא בחירת הבעלים.
9. **כלכלה, שמירה ושפות — לשמר ולבדוק מחדש.** חשבונות, חנות, סקינים, מטבע, XP ומלאי קיימים; מענקי רשת עוברים לכלכלה בצד השרת. ארבע שפות במשחק: עברית, אנגלית, רוסית וערבית. נותר בדיקת שמירה/טעינה, רכישה אטומית, RTL, תרגומים חדשים, סאונד, רגישות ונגישות.
10. **בדיקת קבלה — פתוח.** קרב/נזק/מוות/Respawn/תוצאות, כל הנשקים, צניחה, רכבים, איסוף בשני לקוחות, 2V2, טלפון, FPS, שגיאות גרפיקה וניתוקים. לסכם מה נבדק בפועל ומה לא. לעדכן SETUP_HE, SERVER_SETUP, ADMIN_GUIDE, LOCALIZATION ו-CHANGELOG.
11. **אתר ומיתוג — בסוף.** לעדכן את אתר Scitedra Games הקיים, DROPHAVOC והסיסמה ״צונחים ישר לאקשן.״; עברית ואנגלית עם RTL/LTR. תמונות אמיתיות מתוך הגרסה לאחר בדיקת מולטיפלייר; לתאר רק תכונות פעילות. בדיקת זמינות השם שבוצעה אינה תחליף לבדיקת סימן מסחר.
12. **APK ופרסום — בסוף.** לבנות APK מעודכן, לאמת חתימה/גרסה, לספק הורדה לבדיקה במכשיר ולעדכן קישורים. בדיקת התקנה פיזית דורשת מכשיר זמין ואינה נחשבת שבוצעה רק כי הבנייה הצליחה. להעלות משחק ואתר ולוודא שקישורים והשרת פועלים בגרסה תואמת. אין APK חדש ואין פרסום עד כה.

## סדר העדיפות הנוכחי

## מסירת הכנה לשרת חינמי
נוצר outputs/DROPHAVOC-server-test-source.zip עם המקור ונכסי המשחק, ללא node_modules, נתוני שחקנים או מפתחות פרטיים. הגישה דרך מחבר GitHub דחתה יצירת tree עם 403 Resource not accessible by integration; לא נוצר ענף מרוחק ולא עודכן main. כלי הבדיקה המקומי עבר health/config/rooms ואימות WebSocket; בדיקת הרשת המורחבת עברה גם חסימת גרסאות ישנות. נדרשת התחברות/הרשאת כתיבה לחשבון GitHub וחשבון Render בבעלות המשתמש כדי להמשיך לפריסה בפועל. אין שרת ציבורי חדש פעיל.
