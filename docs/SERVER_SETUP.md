# פריסת DroP-Havoc בחינם לבדיקה
עודכן: 30.10.2026

## המצב שנבדק
- שרת Node המקומי עובד; עברו בדיקות WebSocket לחדר 1V1 וגם 2V2 עם ארבעה לקוחות, קיבולת ופרטיות חדרים.
- https://rivals-go.onrender.com/config ו-/rooms החזירו 404. אין להסיק מכך מה הסיבה בחשבון Render; אין כרגע כתובת ציבורית מאומתת.
- לוח Render מציג התחברות. לא נוצר חשבון ולא הופעל שירות ענן.
- גרסת פרוטוקול משותפת: drophavoc-city-2. שרת לא תואם נדחה; אירוח P2P מופרד מהגרסה הישנה.

## נדרש לפריסה
1. קוד הגרסה המעודכנת בענף GitHub ייעודי; הפריסה חייבת להשתמש בו ולא ב-main הישן.
2. חשבון Render בבעלות בעל המשחק וחיבור לריפו kobifrah1991-svg/RIVALS-GO.
3. Web Service, לא Static Site. Runtime Node 22, Build: npm ci --omit=dev, Start: npm start, Health: /health, תוכנית Free במפורש.
4. מופע יחיד בלבד: החדרים בזיכרון, אין כרגע ניתוב חדרים בין מופעי שרת.
5. Render מגדיר PORT. להשאיר BOTS=4 ו-TRUST_PROXY=1 כפי שמופיעים ב-render.yaml. אין לפתוח פורטים במחשב האישי.
6. ADMIN_CODE נוצר כסוד אצל Render. אין להדביק אותו בצ'אט או בקוד. Google login אופציונלי לבדיקה; בלי GOOGLE_CLIENT_ID ניתן לשחק כאורח.
7. לאחר Deploy: להעתיק את כתובת HTTPS האמיתית ל-shared/servers.js ולבנות מחדש אתר/APK. אין להניח שהשם rivals-go פנוי.

## אימות לאחר עלייה
npm install
node tools/check-server.mjs https://YOUR-SERVICE.onrender.com

הבדיקה דורשת /health=ok, פרוטוקול תואם, רשימת חדרים ו-WebSocket מאומת כאורח. לאחריה לבדוק שני דפדפנים/מכשירים בחדר אמיתי ותנועת משחק; הצלחת health לבדה אינה אישור למולטיפלייר.

## מגבלות סביבת הבדיקה החינמית
Render Free נרדם אחרי 15 דקות בלי תעבורה; התנעה עשויה לקחת כדקה. קבצים מקומיים אינם עמידים באתחול/פריסה. לכן כסף, XP, תפקידים, חסימות ולוגים בסביבה זו זמניים; זו אינה סביבת ייצור.

Upstash יכול לשמר את החשבונות בלבד במימוש הקיים. הוא אינו משמר כיום admins.json, bans.json ולוג אדמין. להפעלה קבועה צריך להשלים אחסון עמיד לכל הנתונים, אימות ושחזור, או דיסק קבוע בתוכנית מתאימה; אין אישור לתשלום.
