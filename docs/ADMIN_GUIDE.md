# מדריך אדמין

## דף הניהול (הכי פשוט)
נכנסים לכתובת **`https://drop-havoc.onrender.com/admin.html`** (או `/admin.html` באתר המשחק).
שם רואים את כל השחקנים המחוברים בכל החדרים, ולכל שחקן יש 4 כפתורים:

| כפתור | מה הוא עושה | מי יכול |
|---|---|---|
| אזהרה | השחקן מקבל הודעת אזהרה על המסך ובצ'אט | מנחה ומעלה |
| השתקת צ'אט | 10 דקות / שעה / יום / שבוע / לתמיד | מנחה ומעלה |
| הוצאה מהמשחק | מנתק אותו מיד (הוא יכול לחזור) | מנחה ומעלה |
| חסימה | לא יכול להיכנס לשרת: שעה / יום / שבוע / לתמיד | אדמין ובעלים |

בוחרים סיבה מוכנה (קללות, הפרעה, לא מקשיב, רמאות...) או כותבים סיבה אחרת.
בלשונית **"חסומים ומושתקים"** אפשר לבטל חסימה או השתקה בלחיצה. בלשונית **"יומן פעולות"** רואים מי עשה מה.
אי אפשר לפעול על מישהו בדרגה שווה או גבוהה ממך.

### מי מנהל
**בעלים** (קבוע בקוד): `kobifrah1991@gmail.com` ו-`scitedra.labs@gmail.com`.
אפשר להוסיף בעלים במשתנה `OWNER_EMAILS` ב-Render (כתובות מופרדות בפסיק), ואפשר לתת "מנחה" או "אדמין" לחברים בפקודה `/setrole` במשחק.

### כניסה עם Google: הגדרה חד-פעמית
1. ב-[Firebase Console](https://console.firebase.google.com) בוחרים את הפרויקט `scitedra-games`.
2. **Authentication ← Sign-in method ← Google ← Enable**.
3. **Authentication ← Settings ← Authorized domains**: מוסיפים `drop-havoc.onrender.com` ו-`kobifrah1991-svg.github.io`.
4. **Project settings ← General ← Your apps**: אם אין אפליקציית Web, לוחצים `</>` ויוצרים אחת. מעתיקים את הערך `apiKey`.
5. ב-Render, בשירות `drop-havoc` ← **Environment**: מוסיפים `FIREBASE_API_KEY` עם הערך שהעתקתם. השרת יופעל מחדש לבד.

ה-apiKey של Firebase הוא מזהה ציבורי ולא סוד. השרת בודק בעצמו את החתימה של Google על כל כניסה.

### כניסה עם קוד (עובדת מיד)
ב-Render ← Environment יש את `ADMIN_CODE` (נוצר אוטומטית). מעתיקים אותו ומדביקים בדף הניהול בשדה "קוד אדמין".

## פקודות צ'אט (אפשרות נוספת)

## איך מקבלים הרשאות
ההרשאות נבדקות **רק בשרת**. שם שחקן לא נותן הרשאה, ושום דבר שהדפדפן שולח לא נותן הרשאה.

1. **לפי חשבון Google** (מומלץ לשרת אונליין): מעתיקים את `config/admins.example.json` ל-`data/admins.json`, ושמים בו את כתובות ה-Gmail ואת התפקידים:
   ```json
   { "you@gmail.com": "Owner", "friend@gmail.com": "Moderator" }
   ```
   התיקייה `data/` לא נשמרת ב-Git.
2. **לפי קוד מפעיל** (לשרת מקומי בלי Google): מפעילים את השרת עם קוד סודי:
   ```bash
   ADMIN_CODE=קוד-סודי-ארוך npm start
   ```
   ובמשחק כותבים בצ'אט: `/adminlogin קוד-סודי-ארוך`. אחרי 3 ניסיונות שגויים בדקה יש חסימה זמנית.

## תפקידים ופקודות

| פקודה | מינימום תפקיד | מגבלות |
|---|---|---|
| `/whoami` | Player | מציג את התפקיד שלך |
| `/announce הודעה` | Moderator | עוברת דרך מסנן הצ'אט ונשלחת לכל החדרים |
| `/kick שחקן [סיבה]` | Moderator | לא על בעל תפקיד שווה או גבוה ממך |
| `/heal שחקן [1-100]` | Admin | ברירת מחדל 100 |
| `/sethealth שחקן 1-100` | Admin | |
| `/giveweapon שחקן rifle\|shotgun\|sniper\|pistol` | Admin | ממלא מחסנית מלאה |
| `/teleport שחקן 1-12\|שחקן` | Admin | לנקודת Spawn או ליד שחקן. נדחה אם היעד בתוך קיר |
| `/ban שחקן [דקות] סיבה` | Admin | הסיבה חובה. ברירת מחדל 60 דקות, מקסימום שנה |
| `/givemoney שחקן 1-10000` | Owner | **לא פעיל** עד שיהיה שירות כלכלה |

- **הגבלת קצב:** 10 פקודות ב-10 שניות לכל אדמין.
- **ממשק:** מקש **F2**, או הכפתור "ניהול שרת" בתחתית המסך, פותחים רשימת שחקנים עם חיפוש. לפני הוצאה או חסימה מופיע מסך אישור.

## לוג Audit
כל ניסיון נרשם, גם ניסיון שנדחה, בקובץ `data/admin-audit.log` (שורת JSON לכל פעולה). כל שורה כוללת זמן, מזהה אדמין, תפקיד, IP, חדר, פעולה, יעד, ערך ותוצאה (`ok`, `denied`, `bad-args`, `failed` או `unavailable`).

## חסימות
החסימות נשמרות ב-`data/bans.json`. שחקן מחובר עם Google נחסם לפי החשבון. אורח נחסם לפי IP, וזה עלול לחסום רשת משותפת שלמה. כדי לבטל חסימה: בדף הניהול, לשונית "חסומים ומושתקים". כשמוגדר Firestore החסימות נשמרות גם שם, כך שהן לא נמחקות כשהשרת החינמי מופעל מחדש.
